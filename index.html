Stables card: the evidence on Minima mainnet

The Stables card works like cash on a phone. Each coin is held by a one-use key inside the phone's secure chip. These pages show where those chip signatures sit in real Minima transactions, how the Council approves a withdrawal, and how anyone can check all of it again.

The repositoryHow it works, the exact contracts as executed, the evidence report, the risk assessment, questions for reviewers, and the code to check it yourself.

How a phone proves that a key lives in its secure chip: Android key attestation, documented by Android in Verify hardware-backed key pairs with key attestation, with Google's own verifier library at android/keyattestation. The Stables card checks the same attestation record with its own code, published in the repository.
